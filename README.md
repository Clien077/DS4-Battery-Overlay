# DS4 电量提示

> **豆包AI生成**：本项目由豆包（Doubao）AI 创作完成，经多轮需求沟通、编码、测试与打包交付。

插入 / 连接 **DualShock 4 (DS4)** 手柄时，屏幕底部居中弹出电量提示，稳定显示 **5 秒**后自动淡出。支持 USB 和蓝牙两种连接方式，也支持手柄一直插着、程序后启动的情况（启动时会先弹一次）。

**额外功能**：
- **充电状态**：插线充电时显示绿色「充电中」；充满显示「已充满」；无线使用只显示百分比
- **低电量提醒**：电量 ≤ 20% 时红色高亮弹窗并停留 8 秒；连接期间每 30 秒自动检查一次，电量跌破阈值会主动弹窗提醒（恢复后重新计时）
- **拔出提示**：手柄断开时弹出「手柄已断开」提示
- **游戏内随时看电量**：游戏中**双击 PS 键**（500ms 内连按两次），立即弹出当前电量窗（窗口始终置顶，不抢游戏焦点）
- **常驻电量横条**：**十字键下 + PS** 组合键，可在屏幕正上方显示/隐藏电量横条（参考图风格：背景全透明、左上状态标签、大号百分比居中并与彩色进度条重叠；进度条随电量变色：≤20% 红色、20–60% 黄色、>60% 绿色；断开时显示"未连接"），显示期间每 5 秒自动刷新一次
- **快捷管理**：双击 **`管理DS4电量提示.bat`**，可一键启动 / 停止 / 重启常驻程序并查看运行状态（不依赖任务管理器）
- **开机自启**：双击 `设置开机自启.bat` 即写入开机自启（HKCU 注册表）；想取消就双击 `取消开机自启.bat`

## 使用（打包版）

本目录已打包为**免 Python 环境**的可执行程序，日常使用只需双击：

1. 双击 **`启动DS4电量提示.bat`** —— 后台启动常驻程序（无需安装任何东西）
2. 程序常驻后台，之后每次插入 / 连接 DS4 都会弹窗；游戏中**双击 PS 键**也会弹窗
3. 想预览界面效果（不需要手柄）：运行
   ```
   ds4_battery_overlay.exe --preview 66
   ds4_battery_overlay.exe --preview-bar 66
   ```

目录结构：
```
ds4_battery_overlay.exe   常驻主程序（无窗口）
ds4_overlay_data\         主程序运行库（不要删除）
ds4_manager.exe           快捷管理程序
ds4_manager_data\         管理程序运行库（不要删除）
*.bat                     双击入口
*.py / *.log              源码与运行日志（可选保留）
```

## 快捷管理

双击 **`管理DS4电量提示.bat`** 打开管理菜单：

```
[1] 启动程序
[2] 停止程序
[3] 重启程序
[4] 查看运行状态
[0] 退出
```

也可以命令行直接操作（适合做快捷方式 / 定时任务）：
```
ds4_manager.exe --start    启动（已在运行则跳过）
ds4_manager.exe --stop     停止
ds4_manager.exe --restart  重启
ds4_manager.exe --status   查看状态
```
管理程序按进程命令行精确匹配 `ds4_battery_overlay`，只操作本程序，不会误杀其它进程。

## 开机自启

- 开启：双击 **`设置开机自启.bat`**
- 取消：双击 **`取消开机自启.bat`**

自启通过注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现，直接指向 `ds4_battery_overlay.exe`，开机即后台常驻。

## 退出

- 右键点击弹出的电量窗 → 立即退出程序；
- 或双击 **`管理DS4电量提示.bat`** 选 [2] 停止；
- 或打开任务管理器，结束 `ds4_battery_overlay.exe` 进程。

## 常见问题

| 现象 | 说明 |
| --- | --- |
| 弹出窗口但显示 `--%` | 手柄被其他软件独占（如 Steam 大屏幕、DS4Windows）时读不到电量。关掉独占程序后重新插入即可。 |
| 游戏里双击 PS 键没反应 | ① 游戏请使用「窗口化 / 无边框全屏」运行，独占全屏（Exclusive Fullscreen）下普通置顶窗口无法显示；② 被 Steam 等软件独占时程序读不到手柄，PS 键监听同样失效。 |
| 单击 PS 键没反应 | PS 键现在是**双击**触发（500ms 内连按两次）。单击不会弹窗，这是刻意设计，避免游戏操作误触。 |
| 电量数值与实际不符 | DS4 电量以 10% 为一档上报（0–10 档），因此显示值只会是 0/10/20/…/100%。这是手柄自身的精度，属正常现象。 |
| 充电状态不显示 | USB 线连接和蓝牙连接都支持「充电中 / 已充满」（由状态字节 bit4/bit5 判断）；只有手柄未处于充电状态时才不显示。 |
| 手柄插入后约 1 秒才弹窗 | 程序以 1 秒为周期轮询设备接入，属正常设计。 |
| 运行后没有任何反应 | 请确认手柄是原装 DS4 或兼容 PID 的设备；其它型号（如 DualSense）不在支持范围。 |
| 拔插手柄后需要重启程序才能恢复 | 已修复。旧版本在"快速拔插/手柄瞬间重新枚举"时可能漏检，导致监听句柄失效；现在程序每秒自检句柄健康，失效即自动重开并重新弹电量，无需重启。 |
| 蓝牙电量一直显示 10% | 已修复。根因：① 蓝牙 DS4 未激活时只发位置报告（无电量），需先读取 FEATURE 报告 0x02（校准数据）切换到完整报告（发送输出报告无法切换）；② 电量字节在蓝牙完整报告的 byte40（此前误读触摸板数据区）。 |
| 蓝牙连接显示 `--%` | 程序在打开蓝牙设备后会先读取校准数据激活完整报告模式。若仍显示 `--%`，请检查是否被 Steam / DS4Windows 等软件独占，关掉后重新连接手柄即可。 |

## 技术说明

- 依赖：`pywinusb`（纯 Python + Windows 系统 `hid.dll`，无需额外驱动）
- 检测：每 1 秒通过 HID 枚举 `VID=0x054C`、`PID=0x09CC/0x0BA0/0x05C4` 的设备，检测接入/拔出状态变化
- 读电量：打开设备，订阅输入报告（USB 为 Report ID `0x01`、64 字节，蓝牙为 `0x11`、78 字节且头部多 2 字节）。**蓝牙需先读取 FEATURE 报告 0x02（校准数据）激活完整报告模式**（否则只发位置报告、无电量无按键；发送 0x11 输出报告无法切换）。解析状态字节：USB 在 byte30、蓝牙完整报告在 byte40，低 4 位为电量档位（0–10 ×10），bit4=充电中、bit5=已充满（蓝牙同时兼容 bit6/bit7）
- 低电量检测：连接期间每 30 秒读取一次电量，跌破 20% 阈值时主动弹窗，并去重（只提示一次，电量恢复到 20% 以上才重新计时）
- PS 键监听：常驻打开手柄句柄，输入报告第 7 字节（USB）/ 第 9 字节（蓝牙）bit0 为 PS 键，第 5 字节（USB）/ 第 7 字节（蓝牙）低 4 位为十字键 POV（值 4 = 下）；**PS 双击**（500ms 内两次按下）弹电量窗，**十字键下 + PS** 组合键切换顶部电量横条
- 电量横条：独立无边框置顶窗口，屏幕正上方居中；背景全透明，左上状态标签（充电中/已充满/DS4/未连接），大号百分比居中并与彩色进度条重叠，进度条随电量变色（≤20% 红 / 20–60% 黄 / >60% 绿），显示期间每 5 秒自动刷新
- 界面：tkinter 无边框置顶悬浮窗，圆角透明背景（Windows 透明色键），淡入 0.2s → 显示 5s → 淡出 0.5s
